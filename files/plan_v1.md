# AI 활용 실무교육 강의계획

> 생성형 AI를 질의응답 수준을 넘어 문서 작업 도구로 활용하도록 Tool Calling·MCP·GitHub 실무교육을 운영하고자 함

## 추진 배경

- 생성형 AI를 질의응답 위주로 사용하여 결과를 한글 문서로 옮기는 수작업 반복
- 도구 호출(Tool Calling)과 MCP 표준 확산으로 AI가 파일을 직접 읽고 문서를 작성하는 여건 마련
- 공무원이 공개한 한글 문서 도구(kordoc, claw-hwp)로 HWP·HWPX 자동화 가능

## 교육 개요

- (일시·장소) 추후 확정, 약 65분
- (대상) 생성형 AI 업무 활용 희망 직원
- (강사) 물정책과 김지훈 주무관
- (방식) 이론 강의 및 보고서 작성 실습 시연

## 교육 내용

| 구분 | 주요 내용 | 시간 |
|---|---|---|
| 도입 | 챗봇과 에이전트의 차이 | 5분 |
| Tool Calling | 도구 정의, 호출 4단계, 에이전트 반복 구조 | 12분 |
| MCP | 표준 연결 구조, 공직 활용 MCP 서버 | 12분 |
| GitHub | 저장소·커밋, CLAUDE.md 기반 맥락 관리 | 15분 |
| 시연 | kordoc·claw-hwp 활용 보고서 작성 | 15분 |
| 마무리 | 요약, 4주 실천 과제, 질의응답 | 6분 |
| 합계 | | 65분 |

## 기대 효과

- 자료 정리·서식 작업 등 반복 문서 업무 시간 단축
- 업무 규칙·자료를 저장소로 관리하여 인수인계 및 재사용 용이

## 향후 계획

- 교육 후 4주 실천 과제 안내(GitHub 가입, 에이전트 설치, MCP 연결, 업무 위임)
- 수강 수요 조사 후 부서별 심화 실습 검토
