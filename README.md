# AI가 1쪽 보고서를 만드는 과정 (강의 시연)

AI 활용 실무교육(Tool Calling · MCP · GitHub) 시연용 페이지입니다.

- **사이트**: https://dochungpikachu.github.io/ai-agent-lecture-demo/
- **주제**: 강의 자료(pptx)를 읽어 강의계획 1쪽 보고서(HWPX) 만들기
- **도구**: [kordoc](https://github.com/chrisryugj/kordoc) 4.24.0 — parse · lint(게이트) · generate · render · validate

## 구성

| 탭 | 내용 |
|---|---|
| ① 시연 재생 | 실제 실행 로그를 대화 · 도구 호출(tool_use / tool_result) · 문서 미리보기로 단계별 재생 (→ / ← / Space) |
| ② 프롬프트 | 라이브 시연에 그대로 쓰는 프롬프트 |
| ③ 결과물 | 최종 HWPX · 원고 내려받기, 고친 이력 |
| ④ 다음 시간에 | 같은 방법을 키워 만든 제주 공약·의회 대시보드(Gongyak) 제작 과정 — gongyak.html |

`files/lecture-plan.hwpx` 는 kordoc 보고서 프리셋으로 생성한 실제 산출물입니다.

## 재생 해설

- 1 요청·도구 목록 전달 → **2 도구 요청 → 3 실행·결과 반환 → AI 확인·재판단**을 필요할 때마다 반복 → **4 최종 답변**.
- 중간 초안·수정 계획은 최종 답변이 아닙니다. 4번은 마지막 장면에서만 표시됩니다.
- 말풍선은 원래 로그를 이해하기 위한 **교육용 재구성**으로, 모델 내부 사고 원문이 아닙니다.
- 핵심 장면 바로가기: 검수 탈락 / 글자 누락 발견 / 검수 통과 후 쪽수 초과 / 최종 답변.
- 요청 횟수는 실제 API 호출 수가 아니라 재생 속 **도구 요청 장면 수**입니다. 연속 도구 호출을 묶은 장면도 있습니다.
