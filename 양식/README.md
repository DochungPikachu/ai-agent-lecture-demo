# 양식 폴더 (보고서 견본)

우리 조직에서 주로 쓰는 보고서 형식의 **빈 견본(HWPX)**을 모아 두는 곳입니다.
AI는 보고서를 만들 때 이 파일을 먼저 읽고, 맞는 견본을 골라 그 서식 그대로 새 내용을 씁니다.

| 폴더 | 들어가는 것 | 역할 |
|---|---|---|
| `자료/` | 읽을 원본 (공개 자료) | 입력 |
| `양식/` | 보고서 견본 | 형식 기준 |
| `결과/` | AI가 만든 HWPX | 출력 |

## 견본 목록

AI는 아래 표를 보고 견본을 고릅니다. 견본을 올리면 이 표에 한 줄씩 추가하세요.

| 파일 | 언제 쓰나 | 분량 | 특징 |
|---|---|---|---|
| (아직 올린 견본 없음) | | | |

- **파일**: `양식/` 안의 파일 이름 (예: `1쪽_현안보고.hwpx`)
- **언제 쓰나**: 어떤 보고에 쓰는지 한 줄 (예: 국·과장 대면보고용 현안 1쪽)
- **분량**: 1쪽, 2~3쪽 등
- **특징**: 요약 상자 유무, 결재란, 항목 부호(□ ○ -), 표 위치 등 AI가 지켜야 할 점

## 견본 올리는 방법

1. 한글에서 평소 쓰는 보고서를 열고 **내용을 지운 빈 양식**으로 만듭니다.
   - 제목 자리, 항목 부호, 표 머리글, 요약 상자 같은 틀은 남깁니다.
   - 본문 예시 문장은 한두 줄 남겨 두면 문체 참고가 됩니다(가상의 내용으로).
2. **HWPX로 저장**합니다 (한글 → 다른 이름으로 저장 → 파일 형식 HWPX). 견본 기능은 HWPX 기준입니다.
3. 파일 이름은 용도가 보이게 붙입니다. 예: `1쪽_현안보고.hwpx`, `추진계획.hwpx`, `회의결과보고.hwpx`
4. GitHub 웹에서 이 폴더로 들어와 **Add file → Upload files**로 올립니다.
5. 위 **견본 목록** 표에 한 줄 추가합니다.

## 올리면 안 되는 것

이 저장소는 **공개 저장소**이고, 템플릿으로 복사해 가는 사본에도 그대로 따라갑니다.

- 결재란의 실명·직위가 적힌 칸, 직인·서명 이미지
- 실제 사업명·금액·수치, 내부 검토 의견
- 개인정보(이름·연락처 등)
- 외부에서 받은 문서의 로고·서식 중 공개해도 되는지 모르는 것

## AI가 견본을 쓰는 방식 (kordoc)

- **서식만 가져오기**: `kordoc generate 원고.md --template 양식/<견본>.hwpx -o 결과/<파일>.hwpx`
  견본의 제목표·담당 줄·요약 상자·항목 부호(□ ○ - ※)·표·참고 띠 서식으로 새 내용을 씁니다.
- **견본 모양 그대로 살리기** (로고·결재란·글꼴까지): 견본을 `--keep-layout-tables`로 읽고,
  틀은 두고 내용만 새로 쓴 뒤 `kordoc patch 양식/<견본>.hwpx 새문서.md -o 결과/<파일>.hwpx`.
- **항목 부호 단계별 글꼴만 맞추기**: `kordoc generate 원고.md --levels-from 양식/<견본>.hwpx -o 결과/<파일>.hwpx`

명령어는 kordoc 사용법 문서(docs/usage.md) 기준입니다. 사람이 직접 칠 필요는 없고, AI에게 "양식 보고 만들어줘"라고 하면 됩니다.
