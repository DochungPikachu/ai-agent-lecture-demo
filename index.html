시연용 프롬프트 (그대로 복사해서 Claude Code · Codex에 붙여넣기)

오늘 강의 「AI 활용 실무교육(Tool Calling·MCP·GitHub)」의 강의계획을 1쪽 보고서로 만들어줘. 1. 이 폴더의 lecture.pptx를 kordoc으로 읽고, 파트별 내용과 시간을 뽑아줘. 2. 구성: 추진 배경 → 교육 개요(일시·대상·강사·방식) → 교육 내용(표: 구분·주요 내용·시간, 합계 행) → 기대 효과 및 향후 계획 3. 제목 바로 아래 요약은 "~하고자 함" 한 문장. 4. 자료에 없는 일시·장소는 지어내지 말고 "추후 확정"으로 써. 5. kordoc 공문서 게이트(보고서 프리셋)로 검수하고, 지적이 있으면 고쳐서 다시 검수해. 6. 통과하면 보고서 프리셋 HWPX(강의계획.hwpx)로 만들고, render로 PNG를 떠서 원고와 대조해 봐. 1쪽을 넘거나 빠진 글자가 있으면 고쳐서 다시 만들어. 7. 끝나면 고친 횟수와 이유를 표로 정리하고, 최종 PNG를 보여줘.

이 프롬프트가 잘 먹히는 이유

  • 입력 파일을 지정 — "lecture.pptx를 kordoc으로" → AI가 어떤 도구를 부를지 바로 정함
  • 구성 순서를 고정 — 왜(배경) → 무엇(개요·내용) → 어떻게(효과·계획)
  • 지어내지 말 것을 명시 — 일시·장소는 "추후 확정"
  • 검수 → 수정 반복을 지시 — 조건부 호출 패턴이 돌아감
  • 눈으로 확인 지시 — render 결과와 원고 대조 (아래 실제 사례 참고)

미리 준비

  • Node.js 20 이상, npx -y kordoc setup 으로 MCP 등록
  • 작업 폴더에 lecture.pptx (강의 자료) 넣기
  • (선택) 다듬기용 claw-hwp: claude plugin install claw-hwp@claw-hwp
  • 네트워크·설치 문제 대비: 이 페이지의 ① 시연 재생을 백업으로

"MCP 누락" 사례가 주는 교훈

kordoc 4.24.0의 stripLawCodes 정규식 [가-힣A-Za-z·]*\s*MCP\s*(?:조회|호출|응답)? 이 원래는 "법령 MCP 조회" 같은 AI 작업 흔적을 지우려는 것인데, 본문에 쓴 MCP도 앞 단어와 함께 지웁니다.

도구는 틀릴 수 있다 → 결과를 눈으로 확인하는 단계(render)를 꼭 넣는다. 오늘 강의의 "사람이 최종 확인" 원칙의 실제 사례입니다.
